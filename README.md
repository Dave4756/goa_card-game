# 고아 카드 게임

방 코드를 공유해 두 사람이 브라우저에서 바로 대전하는 실시간 카드 게임입니다. 카드와 룰은 JSON으로 분리해 두어 이후 카드 추가·수정이 쉽습니다.

## 빠른 시작

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 열고, 한 명이 방을 만든 뒤 방 코드를 다른 사람에게 공유하세요. 두 번째 플레이어가 입장하면 게임이 시작됩니다.

## MVP 기본 규칙

원본 기획에 시작 상태와 행동 횟수가 정의되어 있지 않아, 플레이 가능한 다음 기준을 적용했습니다.

- 양쪽은 일반 몹이 보장된 카드 3장을 받고, 그중 1장을 직접 필드에 배치합니다. 두 플레이어가 배치하면 동전으로 선공을 정합니다.
- 매 턴 덱에서 한 번만 드로우할 수 있고, 몹은 필드 최대 3장까지 배치할 수 있습니다.
- 몹은 턴에 스킬을 한 번 사용할 수 있습니다. 공격 스킬을 쓰면 턴이 자동 종료됩니다.
- 필드의 마지막 몹이 사라지면 즉시 패배합니다. 덱이 비어도 남은 카드로 계속 플레이할 수 있습니다.
- `잠듦`은 다음 자신의 공격 스킬 1회를 취소합니다. 명시되지 않은 세부 상호작용은 인게임 도움말과 로그에서 확인할 수 있습니다.

## 드래그 조작

- 손패의 몹 → 내 빈 필드: 배치
- 손패의 부착/소모 아이템 → 올바른 대상 몹: 사용
- 내 필드 몹 → 상대 몹: 해당 몹의 첫 공격 스킬 사용
- 내 필드 몹 → 자신: 자기 대상 스킬 사용
- 우측 카드 상세의 스킬 버튼 → 대상 몹: 선택한 스킬 사용
- 자연재해?? → 다른 내 몹: 포식

클릭 조작도 모바일 접근성과 카드 상세 확인을 위해 함께 제공합니다.

## Render 배포

1. GitHub에서 빈 저장소를 만들고 이 폴더를 커밋·푸시합니다.
2. Render Dashboard에서 **New → Blueprint**를 선택하고 해당 GitHub 저장소를 연결합니다.
3. 루트의 `render.yaml`을 인식하면 웹 서비스가 생성됩니다. 배포 후 표시되는 URL을 공유하면 됩니다.

이 MVP는 메모리에 진행 중인 방을 보관하므로 단일 Render 인스턴스용입니다. 실서비스 확장 단계에서는 Redis(Socket.IO 어댑터)와 데이터베이스를 연결해야 합니다.
